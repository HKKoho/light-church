# 重要注意事項

- **禮儀**：一律用右手握手、遞物、進食；勿摸他人頭部；勿公共場合吹口哨；勿隨便用手指人
- **禁忌**：進屋脫鞋；忌數字4與黑色；齋戒月勿當眾飲食；入宗教場所需穿著得體，穿長裙／長褲並脫鞋，拍攝需先徵得同意
- **入境申報**：出發前用「All Indonesia」App填寫Arrival Card（個人資料、行程、住宿、健康及海關申報），完成後截圖或下載QR Code，入境時出示
- **行程重點**：VBS教學（分3班）、Joyful School、GKNI祈禱會、主日崇拜、Dayak族長屋、文化體驗、赤道博物館
- 每日設Brief & Pray時間，最後一天設Debrief & Pray
