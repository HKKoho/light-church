## 📄 How to Create PDF from Proposal

The proposal HTML file is now open in your browser. To convert to PDF:

### Method 1: Print to PDF (Recommended)
1. Press `Cmd + P` (File → Print)
2. Click **PDF** button at bottom-left
3. Select **"Save as PDF"**
4. Name it: `MARIA_DIGITAL_TWIN_PROPOSAL.pdf`
5. Click **Save**

### Method 2: Use macOS Preview
1. Open `MARIA_PROPOSAL_FINAL.html` in browser
2. Press `Cmd + P`
3. Click "PDF" → "Open PDF in Preview"
4. In Preview: File → Export as PDF

### Method 3: Online Converter
1. Upload `MARIA_PROPOSAL_FINAL.html` to https://www.html2pdf.com
2. Download PDF
